# Learn Foreign Languages

A simple static website for practicing English and Spanish vocabulary.

The project is intentionally built as a **static website** using HTML, CSS, and vanilla JavaScript. It does not require a backend, database, framework, or build process.

## Features

- Practice **English** and **Spanish** vocabulary
- Multiple vocabulary categories and levels
- Choose how many words you want to practice
- Divide vocabulary into smaller practice sets
- Reveal letters when you need a hint
- Check answers and view your score
- Retry words answered incorrectly
- Audio pronunciation for supported words
- Enable or disable automatic audio
- Keyboard navigation between words
- Light and dark modes
- Responsive design for desktop and mobile

## Available Content

### English

- English C1
- Phrasal Verbs
- Idioms

### Spanish

- Spanish A1
- Spanish A2
- Spanish Numbers

## How It Works

1. Choose a language.
2. Choose a vocabulary category.
3. Select the number of words you want to practice.
4. Choose a word set.
5. Type the correct word or phrase for each definition or translation.
6. Use hints if needed.
7. Check your answers and view your results.
8. Practice the incorrectly answered words again.

## Technologies

- HTML
- CSS
- JavaScript

No backend or external framework is required.

## Running Locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/GiorgiGogsadze/translate-app.git
```

You can also deploy the project directly using a static hosting service such as GitHub Pages.
